# Self-Checkout Shop Billing System 🛒

A modern full-stack application built to streamline the retail checkout process by providing an automated self-checkout experience for customers.

## ✨ Features
* **Self-Checkout System:** Eliminates the need for manual cashier terminals.
* **Automated Billing:** Instant billing calculation for scanned items.
* **Inventory Management:** Tracks product stock in real time.

## 🛠️ Tech Stack
* **Frontend:** React, Vite, CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
